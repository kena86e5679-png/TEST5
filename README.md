# SPATIAL PERCEPTION AR：5m 陣列定位與多人空間系統 (v4)

結合身體運動感知、5m×5m 空間格狀陣列標記、真實建築尺度正交生成與多人視線遮擋的混合實境系統。

---

## v4 五大更新重點

1. **五公尺格狀陣列標記系統 (`A-1` ~ `I-9`)**：
   - 空間中的標記物改為 **每隔 5.0 公尺** 規則排列的 9×9 矩陣陣列（涵蓋 -20m 至 +20m，共 81 個座標錨點：`A-1`, `A-2` ... `I-9`）。
   - 當格點附近偵測到真實牆面或柱角時，標記物會自動微調貼合於物體表面；玩家必須親自走近至 **2.2 公尺內** 才能激活該格點並回傳至伺服器地圖。
2. **Dashboard 即時位置與方向零延遲同步**：
   - 修正先前部分玩家無法即時更新的問題：手機端同步頻率提升至每 `80ms` 一次（包含原地轉向角度變化），且伺服器/主機端每 `350ms~500ms` 主動廣播完整狀態快照（State Snapshot）。
   - `dashboard.html` 新增方向視線扇形錐（FOV Cone）與角度平滑插值，並區分監控端與玩家身分，不會在畫面上產生幽靈原點玩家。
3. **全新設計的 `index.html` 啟動頁面**：
   - 移除所有 Canny 技術字眼，改以冷冽的建築方格圖面美學（Architectural Grid Blueprint）與四宮格模組卡片重新設計介面。
4. **精確對齊真實空間尺度的建築生成**：
   - 透過主導正交軸演算法（Dominant Orthogonal Axis）鎖定真實空間的牆面方位角，使所有長出來的虛擬建築與真實牆面嚴格平行或 90° 正交，不再隨意歪斜亂長。
   - 嚴格採用真實建築模數與人體工學尺度：**標準層高 `2.80m`**、**RC 牆厚 `0.20m`**、**標準門洞 `0.90m × 2.10m`**、**雙人走廊淨寬 `1.50m`**、**結構柱 `0.40m × 0.40m`**、**胸牆掩體高 `1.10m`**（高於腰部、低於 `1.50m` 視高）。
5. **敵人白色虛線外框 ＋ 淡紅色濾鏡**：
   - 偵測到的連機玩家（敵人）以**白色虛線外框**標示，並在敵人框選範圍內覆蓋**淡淡一層紅色濾鏡（`rgba(255, 45, 55, 0.20)` + 紅暈漸層）**；一旦被真實牆柱或虛擬建築遮擋則自動隱藏。
